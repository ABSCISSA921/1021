# 02 · 工具与调试

按“环境 → 节点 → 接口 → 数据 → 时间”的顺序排查。以下无仿真命令使用 [ros_basics](../ros1_learning_ws/src/ros_basics/README.md) 的默认 topics.launch。

## 1. 节点与连接

```bash
rosnode list
rosnode info /basics/talker
rostopic info /basics/counter
rostopic echo /basics/counter -n 3
rostopic hz /basics/counter
rqt_graph
```

依次确认话题类型、发布与订阅关系、消息内容和频率，再观察下游节点的输出。

## 2. 曲线与日志

```bash
rqt_plot /basics/counter/count
rqt_console
rosrun plotjuggler plotjuggler
```

对控制实验，同时记录指令和反馈，并核对单位、时间戳、频率。调节 PID 前先检查反馈有效性与输出限幅，再结合误差和输出曲线调整增益。

C++ 高频日志使用 `ROS_INFO_THROTTLE`，Python 可用 `rospy.loginfo_throttle`。launch 的 `output="screen"` 输出到终端，`output="log"` 写入 ROS 日志目录。

## 3. 参数如何生效

```bash
rosparam get /basics/talker/rate
rosparam set /basics/talker/rate 8
rostopic hz /basics/counter
```

本例只在启动时读取参数，修改服务器上的值后频率不变。通过 launch 的 `rate:=8` 重启才会应用。只有节点主动重新读取，或实现 dynamic_reconfigure 回调，运行行为才随修改更新。

```bash
rosrun rqt_reconfigure rqt_reconfigure
```

此面板显示实现了 dynamic_reconfigure 的节点；普通参数通过 `rosparam` 查看。调参后把最终配置写回 YAML，并重新启动验证。

## 4. rosbag 录制与回放

```bash
rosbag record -O /tmp/counter.bag /basics/counter
# Ctrl+C 停止录制
rosbag info /tmp/counter.bag
# 停止原发布者后回放，避免混入两路数据
rosbag play /tmp/counter.bag
```

PlotJuggler 可直接读取 bag，无需回放。仿真时间回放时，先停掉其他 /clock 来源、设置 `/use_sim_time=true`、再 `rosbag play --clock`。回到普通通信实验时用独立 Master 或恢复 `/use_sim_time=false`。

## 5. 构建与源码定位

```bash
catkin list
catkin build ros_basics
rospack find ros_basics
rosmsg show ros_basics/Counter
rossrv show ros_basics/AddTwoInts
```

修改 .msg/.srv/.action 或 C++ 源码后需要构建；接口变更后重启通信双方。devel 环境里的 launch/YAML 通常直接来自源码；install 环境需重新执行安装。修改 dynamic_reconfigure 的 .cfg 会生成代码，也需要构建。

## 6. C++ 调试与仿真

在 source 了目标工作区的终端启动 IDE，确保包路径与头文件解析一致。可选用 VS Code 或 CLion。命令行调试例子：

```bash
rosrun --prefix 'gdb -ex run --args' ros_pkg v_node
```

Gazebo 插件运行于 `gzserver` 进程中，可附加调试。断点会暂停仿真和控制更新，先保存必要日志。

```bash
roslaunch diffbot_sim diffbot_gazebo.launch gui:=false
gzclient
gz topic -l
rosparam get /robot_description
rosrun controller_manager controller_manager list
```

模型异常时检查 URDF 惯性、碰撞、控制接口与日志；时间错误时检查 /clock、/use_sim_time 和 TF 时间戳。
