# 04 · 常用命令速查(一页纸)

日常开发最常用的命令,按用途分组。更完整的概念解释见 [01-ROS核心概念](01-ROS核心概念.md),调试方法见 [02-工具与调试](02-工具与调试.md)。

## 环境与构建(catkin-tools)

```bash
source /opt/ros/noetic/setup.bash        # 系统环境(每次新终端)
source devel/setup.bash                  # 工作区环境(构建后)

# 工作区初始化与构建(在含 src/ 的目录执行)
catkin init                              # 初始化(一次)
catkin config --extend /opt/ros/noetic   # 指定上层环境(一次)
catkin build                             # 构建全部
catkin build <pkg>                       # 只构建某包
catkin build --no-deps <pkg>             # 只构建某包,不管依赖
catkin clean                             # 清理 build/devel/logs
catkin list                              # 列出工作区发现的包

# 查包信息
rospack find <pkg>                       # 包路径
roscd <pkg>                              # cd 到包目录
rosls <pkg>                              # 列出包内容
```

## 节点

```bash
rosrun <pkg> <node>                      # 运行节点
roslaunch <pkg> <file.launch> [arg:=值]  # 按 launch 启动(可覆盖 arg)
roslaunch --screen <pkg> <file.launch>   # 输出打到当前终端
rosnode list                             # 列出节点
rosnode info <node>                      # 节点的话题/服务/参数
rosnode kill <node>                      # 杀死节点
```

## 话题

```bash
rostopic list                            # 列出话题
rostopic list -v                         # 带类型和收发方
rostopic info <topic>                    # 类型 + 谁发布谁订阅
rostopic echo <topic>                    # 实时打印消息
rostopic echo <topic> -n 5               # 只打 5 条
rostopic hz <topic>                      # 发布频率
rostopic bw <topic>                      # 带宽
rostopic type <topic>                    # 消息类型
rostopic pub -r 10 <topic> <type> "..."  # 以 10Hz 持续发布
rostopic pub -1 <topic> <type> "..."     # 只发一次
```

发布速度指令(最常用的两条):

```bash
# 直行 0.2 m/s
rostopic pub -r 10 /cmd_vel geometry_msgs/Twist "linear: {x: 0.2} angular: {z: 0.0}"
# 哨兵/DiffBot 底盘:0.3 m/s + 0.5 rad/s 旋转
rostopic pub -r 10 /cmd_vel geometry_msgs/Twist "linear: {x: 0.3} angular: {z: 0.5}"
```

> 小技巧:输到 `"` 后按 **Tab** 自动补全消息模板。

## 服务与消息

```bash
rosservice list                          # 列出服务
rosservice call /gazebo/reset_simulation "{}"    # 重置仿真
rosservice call /gazebo/pause_physics "{}"       # 暂停物理

rosmsg show <type>                       # 查看消息结构,如 rosmsg show geometry_msgs/Twist
rosmsg list                               # 所有消息
```

## 参数

```bash
rosparam list                            # 列出参数
rosparam get <name>                      # 读取
rosparam set <name> <value>              # 临时修改(重启节点失效)
rosparam dump params.yaml                # 导出全部
rosparam load params.yaml                # 从文件加载
```

**动态调参**(运行时生效,调 PID 用):

```bash
rosrun rqt_reconfigure rqt_reconfigure   # 图形面板,拖滑条即时生效
# 调完记得把数值抄回包里的 config/*.yaml,否则重启后丢失
```

## TF 坐标变换

```bash
rosrun tf2_ros tf2_echo <frame_a> <frame_b>      # 两坐标系变换(实时刷新)
rosrun tf2_tools view_frames.py                  # 生成 frames.pdf 看整棵 TF 树
rosrun tf2_ros static_transform_publisher \
  x y z yaw pitch roll <parent> <child>          # 发布静态 TF(免写代码)
```

## 调试与可视化

```bash
rqt_graph                                 # 计算图:节点/话题连接关系
rqt_plot /debug/lf_wheel/target/data \
         /debug/lf_wheel/actual/data      # 目标 vs 实际轮速曲线
rqt_console                               # 日志查看
rqt_image_view                            # 图像话题查看
rosrun plotjuggler plotjuggler            # 时间序列分析(调参神器)
rosrun rviz rviz                          # 3D 可视化
```

## 录制与回放(rosbag)

```bash
rosbag record -O tune.bag /debug/lf_wheel/target /odom   # 录指定话题
rosbag record -a                                          # 录全部
rosbag info tune.bag                                       # 查看信息
rosbag play tune.bag                                       # 回放
rosbag play tune.bag --clock                               # 仿真中回放(带 /clock)
# PlotJuggler 可直接 File → Load Data 打开 .bag,无需回放
```

## 遥控与键盘

```bash
rosrun teleop_twist_keyboard teleop_twist_keyboard   # 通用键盘遥控(Twist)
export TURTLEBOT3_MODEL=burger                        # TurtleBot3 车型,launch 前必设

# 舵轮底盘键盘(W/S 前后,A/D 横移,Q/E 旋转,SPACE 急停,G 小陀螺,H 世界系)
roslaunch sentry_chassis_controller sentry_chassis_control.launch gui:=true keyboard:=true
```

## 组合场景速查

| 场景 | 命令序列 |
| --- | --- |
| 谁在发 `/cmd_vel`? | `rostopic info /cmd_vel` |
| 这个话题结构是啥? | `rostopic type /odom` → `rosmsg show nav_msgs/Odometry` |
| 小车不动,排查链路 | `rqt_graph` 看连接 → `rostopic echo /cmd_vel` 看数据 → `rosnode info <控制器>` |
| 调 PID 完整流程 | `tools:=true` 启动 → rqt_reconfigure 调参 → rqt_plot 看跟踪 → `rosbag record` → PlotJuggler 分析 → 抄回 yaml |
| 检查里程计/TF 是否正常 | `rostopic hz /odom` + `rosrun tf2_ros tf2_echo odom base_link` |
| 定位建图问题 | `rosrun tf2_tools view_frames.py`,确认 map→odom→base_link 链条存在 |
