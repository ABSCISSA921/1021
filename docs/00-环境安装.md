# 00 · 环境安装

本仓库所有代码以 **Ubuntu 20.04 + ROS 1 Noetic** 为基准环境。请先完成本章,再进行任何工作区构建。

## 1. 系统要求

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Ubuntu 20.04 LTS (Focal) | ROS Noetic 官方只支持 Focal,不要用 22.04/24.04 |
| 桌面 | 有桌面环境 | Gazebo / RViz / rqt 都是 GUI 程序 |
| 显卡 | 集显即可跑通;独显体验更好 | Gazebo 对 GPU 要求不高 |
| 磁盘 | 建议 ≥ 40 GB 空闲 | ROS + Gazebo + 各依赖约占 10 GB |
| 内存 | ≥ 8 GB | 多机器人仿真吃内存 |

三种安装方式任选其一:

- **双系统 / 物理机**:体验最好,驱动问题最少。
- **虚拟机 (VMware / VirtualBox)**:适合尝鲜,但 Gazebo 渲染可能很卡;开启 3D 加速可缓解。
- **Docker 容器**:环境干净可复现,但需要额外配置 GUI 转发(X11),适合有一定基础的同学。本仓库的 CI 也使用 `ros:noetic-ros-base-focal` 容器。

> WSL2 不推荐:Noetic 的图形程序(Gazebo/RViz)需要 X 转发,排错成本高于收益。

## 2. 安装 ROS Noetic

以下为官方桌面完整版(desktop-full)安装,包含 Gazebo、RViz、rqt 全家桶。建议先换国内镜像加速:把 `http://packages.ros.org` 替换为清华源 `https://mirrors.tuna.tsinghua.edu.cn/ros/ubuntu`(中科大 `https://mirrors.ustc.edu.cn/ros/ubuntu` 亦可)。

```bash
# 1. 添加 ROS 软件源
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt install curl
curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.key | sudo apt-key add -

# 2. 更新并安装桌面完整版
sudo apt update
sudo apt install ros-noetic-desktop-full

# 3. 安装构建工具链(本仓库的必备项)
sudo apt install python3-catkin-tools python3-rosdep python3-pip
```

> 本仓库统一使用 `catkin build`(catkin-tools),**不要**使用 `catkin_make` 或 `catkin build_isolated`。

## 3. 初始化 rosdep

`rosdep` 用于根据 `package.xml` 自动安装系统依赖。每个新系统只需执行一次初始化,之后更新索引即可:

```bash
sudo rosdep init
rosdep update
```

- `sudo rosdep init` 如果提示 `already exists`,说明已经初始化过,跳过即可。
- 国内网络 `rosdep update` 经常超时,可改用 [rosdepc](https://github.com/fishros/rosdepc)(小鱼的一键 rosdep 国内代理方案)或配置代理;多试几次通常也能过。

> ⚠️ **noetic 已 EOL 的必踩坑**:新版 rosdep(0.21+)的 `rosdep update` 默认**跳过 end-of-life 发行版**,直接跑会导致 `rosdep install` 解析不出任何 ROS 包(`Cannot locate rosdep definition for [tf/xacro/...]`)。正确做法是先升级 rosdep 并带参数更新:
>
> ```bash
> sudo pip3 install -U rosdep
> rosdep update --include-eol-distros --rosdistro noetic
> ```
>
> 本仓库 CI 已按此配置;本地装依赖时同样需要这一步。

## 4. 配置环境变量

把 source 命令写入 `~/.bashrc`,之后每次打开终端自动生效:

```bash
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

验证安装:

```bash
printenv | grep ROS
# 应看到 ROS_DISTRO=noetic、ROS_PACKAGE_PATH 等变量

roscore
# 正常会打印 "started core service [/rosout]",Ctrl+C 退出
```

## 5. 附加工具(推荐)

```bash
# PlotJuggler:时间序列调试,舵轮控制器调参必备
sudo apt install ros-noetic-plotjuggler

# 键盘遥控(teleop_twist_keyboard 一般已随 desktop-full 安装)
sudo apt install ros-noetic-teleop-twist-keyboard

# MoveIt(进阶教程需要,体积较大)
sudo apt install ros-noetic-moveit
```

## 6. 拉取本仓库

```bash
git clone --recurse-submodules git@github.com:ABSCISSA921/1021.git
cd 1021
git submodule status --recursive
```

所有第三方依赖都以子模块固定提交的方式管理,保证任何时间克隆得到的代码都能复现。详见根目录 [README](../README.md) 的「获取源码」一节。

## 7. 一次完整的依赖安装

```bash
source /opt/ros/noetic/setup.bash
cd 1021
rosdep install --from-paths ros1_learning_ws/src ros1_advanced_ws/src dx_final/src --ignore-src -r -y
```

- `--ignore-src`:不安装 `src` 里已有的源码包,只装缺失的系统依赖。
- `-r`:个别无法解析的依赖不报错中断,便于手动补装。
- `-y`:自动确认。

之后进入任一工作区执行 `catkin build` 即可,构建方式见各工作区 README。

## 8. 安装验证清单

按顺序全部通过即环境就绪:

1. `roscore` 能启动;
2. `roslaunch` 能补全到任意包;
3. 根目录 `rosdep install` 无致命报错;
4. `ros1_learning_ws` 能 `catkin build` 成功;
5. `roslaunch diffbot_sim diffbot_gazebo.launch` 能看到 Gazebo 里的小车。
