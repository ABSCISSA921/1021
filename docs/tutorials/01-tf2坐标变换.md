# 01 · tf2 坐标变换教程

> 对应工作区:`ros1_advanced_ws`,子模块 `geometry_tutorials`(ros/geometry_tutorials,noetic-devel,固定提交 `d365875`)。

tf2 是 ROS 的坐标系管理系统,一切「位置相关」的功能(里程计、激光、导航、机械臂、舵轮底盘的世界坐标控制)都建立在其上。本教程是 ROS **必修课**。

## 学习目标

1. 理解坐标系树(frame tree)与父子关系;
2. 用 `tf2_echo`、`view_frames` 检查 TF;
3. 读懂 broadcaster / listener 的最小代码;
4. 能自己发布静态与动态 TF。

## 运行官方演示(turtle_tf2)

```bash
# 终端 1:经典乌龟跟随演示
roslaunch turtle_tf2 turtle_tf2_demo.launch
```

## 核心概念

### 1. 一棵树,不是一张网

```text
world ──> turtle1 ──> turtle1_follower(例子)
   └────> turtle2
```

- 每个坐标系**有且只有一个父坐标系**,整棵树上任意两点都存在唯一路径;
- 变换 `A→B` 表示「B 在 A 下的位姿」;`turtle1 → turtle2` 是「turtle2 在 turtle1 下的位姿」;
- 机器人里典型链条:`map → odom → base_link → laser`。

### 2. Broadcaster 发布,Listener 查询

```cpp
// 广播:每周期发布 world -> turtle1 的变换
geometry_msgs::TransformStamped t;
t.header.frame_id = "world";        // 父
t.child_frame_id  = "turtle1";      // 子
t.transform.translation.x = x;      // 位置
t.transform.rotation = q;           // 姿态(四元数)
br.sendTransform(t);

// 查询:turtle2 在 turtle1 下的位姿
auto tr = buffer.lookupTransform("turtle1", "turtle2", ros::Time(0));
tr.transform.translation.x;         // 相对位置
```

- `ros::Time(0)` 表示「最新可用的变换」;
- 查询可以发生在**任何两个坐标系之间**,不需要它们有直接父子关系。

### 3. 时间与缓冲

tf2 用 10 秒环形缓冲保存历史变换,支持「查询 5 秒前的相对位姿」(time travel)。查得太老会报 `extrapolation` 异常,仿真中必须 `use_sim_time=true`。

## 动手:发布静态 TF

两台小车之间是**固定**关系时用静态广播器,免写代码:

```bash
rosrun tf2_ros static_transform_publisher \
  0.5 0 0 0 0 0 world robot_A   # x y z yaw pitch roll 父 子
```

验证:`rosrun tf2_ros tf2_echo world robot_A`。

## 代码导读(`geometry_tutorials/turtle_tf2`)

| 文件 | 内容 |
| --- | --- |
| `src/turtle_tf2_broadcaster.cpp` | 订阅 `/turtleX/pose`,广播 `world → turtleX` |
| `src/turtle_tf2_listener.cpp` | 查询 `turtle1 → turtle2`,用比例控制输出 `/turtle2/cmd_vel` |

listener 的核心逻辑只有三步:**查相对位姿 → 算误差 → 发速度**。这也是本仓库 `xp_second_pkg` 跟随算法的同款套路,建议对照阅读。

## 练习任务

1. 把 listener 的跟随增益改成参数服务器参数,`rqt_reconfigure` 在线调;
2. 把 tf2 查询换成 `transform(tf2_ros::Buffer&, ...)` 变换一个 `PointStamped`,体会「点变换」与「位姿查询」的区别;
3. 在 `multi_turtlebot3.launch` 中加一台 `tb3_2`,广播它的 TF 并让它跟随 `tb3_1`(形成跟随链)。

## 与舵轮项目的关联

舵轮控制器「世界坐标系控制」(`use_world_frame=true`)的 `transformVelocity()` 正是本教程 listener 的翻版:把 `odom` 系下的速度矢量通过 `tf_buffer_.transform(v_world, "base_link", ...)` 变到车体系再执行。**不掌握 tf2,就读不懂舵轮控制器这段代码。**
