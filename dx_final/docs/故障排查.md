# dx_final · 故障排查

仅针对本项目。构建与启动见[项目 README](../README.md)。


### launch 找不到 Gazebo 插件
确认 `rm_control`、`rm_description_for_task` 两个子模块已初始化,并且加入子模块后**重新构建过**工作区。

### 机器人在 Gazebo 里抽搐 / 起步暴冲
1. 用 `rqt_reconfigure` 把对应轮的 `*_wheel_p` 调小;
2. 检查 `config/chassis_params.yaml` 里的 `acc_linear`(m/s²)是否过小——过小会表现为「加油不走、松手还滑」。

### 车跑不直 / 自转漂移
1. 检查四轮 `offset_*` 舵机零偏是否为 0(Gazebo 中无需补偿);
2. 用 `rqt_plot` 对比四轮 `/debug/*_wheel/target` 与 `actual`:某轮明显掉速 → 增大该轮 P 或检查 `wheel_direction` 符号;
3. 里程计漂移可用 `odom_linear_scale` / `odom_angular_scale` 微调(见控制器 README 参数表)。

### 功率限制日志刷屏
`Power Limit Triggered!` 表示虚拟电容能量不足、力矩被 `k_scale` 缩放。正常规则行为;想深入了解见控制器 README「功率限制」一节。

### `rm_description` 与 `rm_description_for_task`
- `rm_description_for_task` 是**仓库目录名**;
- `rm_description` 是**ROS 包名**(package.xml 里定义);
- launch 里 `$(find rm_description)` 按 ROS 包名查找路径。
